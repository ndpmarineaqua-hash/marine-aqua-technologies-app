# MARINE AQUA TECHNOLOGIES

Smart Aquaculture. Better Results.

Fresh Flutter starter UI for Marine Aqua Technologies.

## Included
- Home dashboard
- Products
- My Ponds
- Technical Support
- Profile
- Android APK build
- Android App Bundle (AAB) build

Product content is based on the Marine Aqua Technologies brochure supplied for this project.
